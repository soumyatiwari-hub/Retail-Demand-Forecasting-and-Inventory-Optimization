## 1. Project Overview

Retail businesses need accurate demand forecasting to maintain the right inventory levels. Predicting customer demand helps reduce stock shortages, minimize excess inventory, and improve operational efficiency.

This project uses the Walmart M5 Forecasting dataset to build a complete demand forecasting pipeline. The workflow includes data preprocessing, exploratory data analysis, feature engineering, forecasting using Prophet and LightGBM, and visualization through Tableau dashboards.
## 2. Problem Statement

Retail companies often struggle with inventory management because future product demand is uncertain.

If demand is underestimated:

- Products become unavailable.
- Customers become dissatisfied.

If demand is overestimated:

- Inventory costs increase.
- Products remain unsold.

The objective of this project is to develop a forecasting system that predicts future sales and supports better inventory planning.
## 3. Objectives

The main objectives of this project are:

- Train forecasting models.
- Evaluate model performance.
- Develop Tableau dashboards.

The dataset is widely used for retail demand forecasting research and machine learning applications.

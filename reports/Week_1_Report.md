# Week 1 Report – Retail Demand Forecasting & Inventory Optimization

## Objective
Prepare and explore the Walmart M5 retail sales dataset for demand forecasting by loading, cleaning, merging, and analyzing the data.

## Work Completed

### Data Loading
- Loaded the Walmart M5 datasets:
  - Sales Data
  - Calendar Data
  - Sell Prices Data
- Explored the structure of each dataset using `.head()`, `.info()`, and `.shape()`.

### Data Cleaning
- Checked for missing values.
- Handled null values where necessary.
- Verified data types and prepared the datasets for analysis.

### Data Merging
- Merged the sales, calendar, and sell prices datasets into a single master dataset.
- Ensured the merged dataset was suitable for further analysis and forecasting.

### Exploratory Data Analysis (EDA)
- Analyzed sales trends over time.
- Examined product and store-level sales patterns.
- Created visualizations to understand demand distribution and seasonal trends.

### Dataset Preparation
- Saved the cleaned and merged dataset for use in the forecasting phase.
- Organized project files and maintained a structured workflow.

## Outcome
Successfully completed data preprocessing and exploratory analysis. The project now has a clean and integrated dataset that is ready for feature engineering and forecasting in the next phase.
